# 0xCaptain888

I build the control plane for autonomous AI agent actions.

> Agents can act, but never beyond policy.

## Core project

[Agent Control Plane](https://github.com/0xCaptain888/agent-control-plane) is policy-controlled, verifiable execution infrastructure for autonomous AI agents.

```text
Intent → Policy → Risk → Execute → Verify → Recover → Receipt
```

## What it enables

- Autonomous trading with bounded permissions
- Agent payments and API procurement
- Treasury automation and rebalancing
- Agent-to-agent task execution
- Verifiable execution, recovery, and audit receipts

## Reference applications

- [Agent Control Plane](https://github.com/0xCaptain888/agent-control-plane) — core SDK and lifecycle
- [agentpay](https://github.com/0xCaptain888/agentpay) — wallet, budget, and payment experiments
- [agentbank](https://github.com/0xCaptain888/agentbank) — treasury reference application
- [agentcourt](https://github.com/0xCaptain888/agentcourt) — proof, evidence, and dispute reference
- [kitehive](https://github.com/0xCaptain888/kitehive) — agent economy reference

## Current focus

Building reusable adapters for exchanges, chains, x402, MCP, and workflow runtimes while keeping the control plane domain-neutral.
